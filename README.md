# Quotation Domain Microservice

## 📋 Overview

This microservice is responsible for calculating cost estimates for 3D printing projects. It takes into account various parameters such as material type, size, complexity, and shipping costs to provide an accurate quotation.

## 🚀 Features

- **Cost Calculation**: 💰 Accurate estimation based on material, size, and complexity.
- **Shipping Costs**: 🚚 Add shipping costs to the total quotation.
- **Modular Design**: 🧩 Organized structure for easy maintenance and scalability.
- **RESTful API**: 🌐 Seamless integration with other services.
- **Terraform Configuration**: 🏗️ Infrastructure as code for easy deployment and management.
